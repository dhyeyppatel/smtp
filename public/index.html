Developer API Integration

Ready-to-use snippets for OTPs, broadcasts, password resets, and greetings.

JavaScript (fetch) — Send Project Broadcast 
await fetch("https://your-service.vercel.app/api/broadcast", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key": "sk_abc_dev123" // Broadcasts to all users of abc
  },
  body: JSON.stringify({
    subject: "Monthly Newsletter",
    title: "What's new in our platform",
    message: "<p>Here are your latest product updates...</p>",
    action_url: "https://myapp.com/blog",
    action_label: "Read Article"
  })
});
cURL — Global All-Projects Broadcast (Master Key) 
curl -X POST https://your-service.vercel.app/api/broadcast/all \
  -H "Content-Type: application/json" \
  -H "X-API-Key: master_secret_change_me_12345" \
  -d '{
    "subject": "Scheduled Maintenance Announcement",
    "title": "System Update on Sunday",
    "message": "<p>All project APIs will remain operational.</p>"
  }'
Python (requests) — Send OTP 
import requests

res = requests.post(
    "https://your-service.vercel.app/api/send-otp",
    headers={"X-API-Key": "sk_abc_dev123"},
    json={"email": "user@example.com"}
)
print(res.json())
